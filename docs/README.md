## Planning Documentation

### What is this ?

This is place holder in `ROOTPATH/docs` for writing planning document for any new project beeing started with launchpad.

Managed from frontend/system controller and views only, all documents files are in `ROOTPATH/docs` path. That you will replace in new project and syncing from launchpad will not affect /docs folder

### How to start ?

This content (that you are reading) is in `/docs/README.md`, you can freely modify it.

Define your files as per required modular structure in `/docs/directory/subDirectory/myFile.md` file style.

Modify navigation file `docs/_sidebar.md` and define paths to your original .md file.
