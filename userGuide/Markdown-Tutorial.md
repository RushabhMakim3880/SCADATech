# 📘 Markdown Formatting Tutorial

This tutorial shows how to write Markdown with examples. All formatting is shown using visible code blocks.

---

## 🔹 Headings

Use `#` symbols for headings:

```
# H1 Heading
## H2 Heading
### H3 Heading
#### H4 Heading
```

**Output:**
(Just like the headings you see in this page)
---

## 🔹 Bold & Italic

Use `*` or `_` for emphasis:

```
*italic* or _italic_

**bold** or __bold__

***bold italic***
```
**Output:**

*italic* or _italic_

**bold** or __bold__

***bold italic***


---

## 🔹 Lists

Unordered list:

```
- Item 1
- Item 2
  - Sub-item
```

**OUTPUT:**
- Item 1
- Item 2
  - Sub-item

Ordered list:

```
1. First
2. Second
   1. Sub-numbered
```
**Output:**
1. First
2. Second
   1. Sub-numbered
---

## 🔹 Links

```
[OpenAI](https://www.openai.com)
```

**Output:**
[OpenAI](https://www.openai.com)
---

## 🔹 Images

```
![Alt Text](https://placehold.co/600x100/EEE/31343C)
```

**Output:**
![Alt Text](https://placehold.co/600x100/EEE/31343C)
---

## 🔹 Code

Inline code:

```
Use \`your_code_here()\` for inline code.
```

**Output:**
Use `your_code_here()` for inline code.

Multiline code block:

<pre>
```php
echo "Hello World";
```
</pre>

**Output:**
```php
echo "Hello World";
```
---

## 🔹 Blockquotes

```
> This is a quote.
> It can span multiple lines.
```
**Output:**
> This is a quote.  
> It can span multiple lines.
---

## 🔹 Horizontal Line

```
---
```
**Output:**
(see the line below)
---

## 🔹 Tables

```

|----------|-----|
| Alice    |  24 |
| Bob      |  30 |
```

**Output:**

| Name     | Age |
|----------|-----|
| Alice    |  24 |
| Bob      |  30 |

---

## 🔹 Task List

```
- [x] Task done
- [ ] Task pending
```

**Output:**

- [x] Task done
- [ ] Task pending

---

## 🔹 Collapsible Section

```
<details>
  <summary>Click to expand</summary>

  Hidden content here.
</details>
```

**Output:**

<details>
  <summary>Click to expand</summary>

  Hidden content here.
</details>

---

## 🔹 YouTube Embed (HTML inside Markdown)

```
<div class="video-wrapper">
  <iframe src="https://www.youtube.com/embed/0ak-wKMq_dM?si=jb_OdJlHy1iFz4Ej"
          allowfullscreen>
  </iframe>
</div>
```

**Output:**

<div class="video-wrapper">
  <iframe src="https://www.youtube.com/embed/0ak-wKMq_dM?si=jb_OdJlHy1iFz4Ej"
          allowfullscreen>
  </iframe>
</div>
