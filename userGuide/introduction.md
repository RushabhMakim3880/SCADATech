# LaunchPad Introduction

**LanuchPad** is **CI4 (CodeIgnitor 4)** starter template to **start new project** from. Its **packed with** lots of ready made **features, codes, libraries** included and tools to help you **speed up the development** of new project.

## Features

1. SAAS Ready setup with tenantId in all tables and built in tenantManager.
2. Seperated Frontend & Backend With JWT Auth Token.
3. Backend Ready to be used with any other cliet like mobile app as well.
4. Built In Groups/Users/Plan/Settings Management.
5. Automatically management of api calls, responses, login, auth, etc.

## Advanced Features

1. TOTP for Two Factor Authentication.
2. Inbuilt Image Captcha for Login Protection.
3. Login security with Lock on failed attempts, lock duration, password validity etc.
4. Web Push Notificaiton.
5. PWA Ready.
6. Auto ApiDocs Generator.
7. Built In Filesize and filetype control/protection for file uploads.
8. Built in Permission Management
9. Multiple Theme Support.
10. Auto Chart Generation System.
11. Auto Datatable management system with added features.
12. Form cache system.
13. auto crud form 


## Spark Commands

1. Code Generator for crud operations from db table name.
2. Migrate, seed and reset option.
3. Sync option to sync latest changes from launchpad to on going projects.
4. Permission Scanner.
5. Seed Ordering Assistance.
6. Future: db validation as per standard rules for detecting missing or human errors.


## Libraries Included

1. Echarts for charts and graphs.

3. Notification (SweetAlert2, Toastr, NotyF)
4. Select2
5. jQuery DataTable.
6. Color Picker
7. Icon Picker
8. GridStack for dynamic Dashboard.
9. Image Upload with browser side crop and resize.
10. Tippy (Tooltip on mouse hover)
11. Sortable (for menu drag/drop management).
12. International Mobile Number format.
13. Location Picker (to pick location latlong from map)
14. Barcode/QR scanning with phone camera
